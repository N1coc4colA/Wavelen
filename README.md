# Wavelen
Web audio player with online source &amp; persistent local storage.

## Dependencies
You just need Docker Compose.

## Setting up
You can create your own _.env_ file from _.env.default_ and replace the values with the ones that you want.

## Running
If you just want to run it:
```
$ docker-compose up
```
If you want to build and run:
```
$ docker-compose up --build
```
